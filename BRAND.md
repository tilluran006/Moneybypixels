# MoneyByPixels brand rules (Ledger Paper)

**Name:** MoneyByPixels (one word). **Handle:** @moneybypixels. **Tagline:** India's money, in numbers.

## Colour

| Name | HEX | Use |
|---|---|---|
| Ledger Paper | #F5EFE3 | Default background |
| Slip | #FFFCF5 | Receipts, statements, method box |
| Ink | #1B1814 | Text |
| Ink Soft | #5C5249 | Secondary text, sources, axis labels |
| Signal Orange | #BD3F0E | The one accent: hero numbers, main series, kickers |
| Ledger Blue | #17405F | Comparison series only (dashed) |
| Context Grey | #C2B8AA | Non-highlighted bars; never text |
| Marker | #F6DCC2 | Highlighter band behind words |
| Hairline | #D9D0C1 | Rules |
| Night | #14110E | News covers and Night verdict slides |
| Chalk | #EFE8DB | Text on Night |
| Ember | #F08A3C | Accent on Night |

- Orange is an accent only, never a full background (it reads as saffron).
- No red or green for gain/loss; use ▲ ▼ and + − signs.

## Type

Source Serif 4 SemiBold for headlines and big numbers; Source Sans 3 for everything else; IBM Plex Mono inside receipts only. All three set ₹. Minimum text size 28px; source line 24px.

## Layout

1080×1350. 90px side margins. Header: orange square + wordmark top-left, counter top-right. Footer on data slides: assumptions, then "Source: … · Educational, not financial advice." Cover content stays between y 150 and 1200 (profile grid crop).

## Rhythm

- Educational posts: Paper cover. News posts: Night cover with one huge number. No AI photos of real people or events.
- Verdict slide alternates Night and Paper from post to post.
- 6 to 8 slides, one idea per slide, never the same template twice in a row.
- Every post ends with a sources slide.
